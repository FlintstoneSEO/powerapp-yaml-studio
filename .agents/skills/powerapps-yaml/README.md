# powerapps-yaml skill

Use this skill when implementing or reviewing YAML generation logic.

## Practical guidance
- Always require and honor a selected Power Apps version.
- Apply the global theme profile consistently in generated output.
- Prefer deterministic generation (same input -> same YAML).
- Validate required fields before generation and return actionable errors.
- Keep generated YAML copy/paste-ready for Power Apps Studio.

## Done checklist
- Version-aware behavior verified.
- Theme influence verified.
- Output format sanity-checked with representative examples.
