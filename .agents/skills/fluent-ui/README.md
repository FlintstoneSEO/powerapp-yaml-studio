# fluent-ui skill

Use this skill for frontend UI and UX work.

## Practical guidance
- Use Fluent UI v9 components and styling patterns.
- Build responsive layouts that work on common desktop/laptop widths.
- Prioritize accessibility: labels, keyboard support, focus states, contrast.
- Keep component structure simple and beginner-friendly.
- Prefer reusable UI building blocks over one-off patterns.

## Done checklist
- Fluent UI v9 usage is consistent.
- UI is responsive and accessible.
- UX flow is clear for first-time users.
