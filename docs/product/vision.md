# Product Vision

## Product summary
PowerApp YAML Studio is a guided tool for generating Power Apps YAML that users can copy/paste directly into Power Apps Studio. It aims to reduce trial-and-error and help users produce valid, version-aware YAML quickly.

## Target users
- Citizen developers building apps in Power Apps.
- Makers who prefer guided UI flows over writing YAML manually.
- Teams that need consistent app structure and theming across projects.

## Core features
- Form-based and assisted YAML generation.
- Output tuned to the selected Power Apps version.
- Global theme profile support that influences generated YAML.
- Backend-assisted guidance grounded in Microsoft Learn documentation.
- Easy copy/paste workflow into Power Apps Studio.

## MVP scope
- Basic UI for collecting app configuration inputs.
- Backend API endpoint(s) that generate YAML from validated inputs.
- Version selection and theme profile applied in generation logic.
- Clear output panel with copy support.
- Essential validation and error feedback for common input issues.

## What success looks like
- Users can generate usable YAML in minutes without manual formatting.
- Generated YAML aligns with chosen Power Apps version and theme profile.
- Early users report fewer YAML errors after pasting into Power Apps Studio.
- The codebase remains easy for contributors and Codex to extend in small, testable increments.
